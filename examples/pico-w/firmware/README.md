# CYW43439 NVRAM

`nvram_rp2040.bin` configures the Pico W's CYW43439 Wi-Fi chip. It comes
from the [embassy](https://github.com/embassy-rs/embassy) repository
(`cyw43-firmware/`, at tag `embassy-rp-v0.10.0`) and is distributed under
the Permissive Binary License 1.0 in
`LICENSE-permissive-binary-license-1.0.txt`. The Wi-Fi firmware itself comes
from the `cyw43-firmware` crate.
